# 🛒 Mobile-Responsive E-Commerce Website

A multi-page, fully responsive e-commerce storefront built with **vanilla HTML, CSS, and JavaScript** — no frameworks. Designed mobile-first so the layout adapts cleanly from phones to desktop.

## ✨ Features

- **Home page** with hero section and featured products
- **Category browsing** (tech, clothing, interior)
- **Product detail pages** rendered from a JavaScript product catalog (`products.js`)
- **Shopping cart** with add/remove and total calculation (`cart.js`)
- **User profile page** (`profile.js`)
- **Fully responsive layout** via dedicated responsive stylesheets

## 🛠 Tech Stack

- HTML5 · CSS3 (flexbox/grid, media queries) · Vanilla JavaScript
- No build step — runs directly in the browser

## 🚀 Run Locally

```bash
git clone https://github.com/Ahsan-muhd-444/Mobile-responsive-ecommerce_website_Muhammad_Ahsan.git
```

Then open `index.html` in any browser. No server or dependencies needed.

## 📂 Pages

| File | Purpose |
|---|---|
| `index.html` | Landing page |
| `category.html` | Category listing |
| `product.html` | Product details |
| `cart.html` | Shopping cart |
| `profile.html` | User profile |
